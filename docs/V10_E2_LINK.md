# V10-E2：NMS 后的降噪与局部连接实验

本版以已经完成色彩调整、实板可以正常显示的 E1 为直接基础，响应用户在 T=50 下“NMS 细但不连续”的反馈。稳定 C2.1 与 E1 原目录、固件和发布包全部保留。本版尚未上板，不自动取代稳定版本。

## 可以直接烧录的两个版本

| 文件（位于 programming） | 普通页标识 | 算法 |
|---|---|---|
| `ti60f225_oob_V10_E2_Link.bit` | E2L | 原 Sobel + 原 NMS + 方向约束的局部弱边缘连接与小分量抑制 |
| `ti60f225_oob_V10_E2_NMS.bit` | E2N | 原 Sobel + 原 NMS，关闭新增连接；同样的默认 T、显示规则与延迟 |

两版默认 **T=50（高阈值 H）**。连接版自动采用 **L=ceil(H/2)**，所以 T=50 对应 L=25。没有增加按键，也没有把所有大于 25 的响应直接显示成白线。弱候选必须通过下面的方向、邻接和强种子支持条件。

先在相同机位、照明、预处理和 T=50 下比较 E2N 与 E2L，避免把 T=24 与 T=50 的差异算作连接算法收益。E1N/E1S 仍保留在原 E1 目录，适合回退及复查。

## 对断线与噪点的判断

原 Sobel 的 Gx/Gy、11 位 L1 幅值和阈值算术没有发现溢出或 8 位提前截断，本轮继续保持。M5 的饱和到 255 仅用于显示，算法仍比较完整幅值。

NMS 沿梯度法线筛掉非峰值响应，线条会变细；它本身不会恢复低于高阈值的细节，也不会去掉所有孤立峰值。降低单阈值会同时增加弱轮廓和背景噪点。某些角度量化、平台和数字曲线也会造成短缺口。因此本版保留 E1 的平台规则，只在 NMS 后增加可关闭的连接步骤。

另有一个独立的显示问题：原 M3 右半图只取每对源像素的偶数列，单像素边缘位于奇数列时可能完全消失。本版对二值预览采用相邻两列 OR，左半 RGB 仍取原偶数列。该修正只避免缩略显示漏线，不改变 M2/M4 的实际检测结果；不能把它作为算法召回提升来计数。

## 新增 RTL 规则

1. **候选和种子。** 低候选为通过原 NMS 且幅值不低于 L 的像素；强种子为通过 NMS 且幅值不低于 H 的像素。方向继续使用 E1 的四档梯度法线。
2. **有限短桥。** 中心本身未通过 NMS，但原始幅值不低于 L，且沿轮廓切向的两个相反邻居均为低候选，三点法线分档完全一致时，中心可以作为弱桥。桥不产生强种子；零梯度空白不会被无条件填白。不进行整体膨胀或闭运算。
3. **方向约束。** 5×5 局部图中的邻接是对称的：不允许两端法线相差 90°，也不允许沿任一端的精确法线方向连接。水平/垂直/两种对角移动分别按方向分档检查，减少跨过轮廓厚度、连接相邻杂点的机会。
4. **局部可达性。** 从窗口中心出发，经过 24 级流水展开，求出该 25 点图内的完整可达集合。它不是只看相邻一圈，但空间范围始终为中心 5×5；桥只在内部 3×3 生成，保证两端数据都在窗口内。
5. **支持度。** 默认要求中心所属局部集合至少 3 个候选像素，且至少 **3 个强种子**。单个和两个强噪点会被拒绝；有邻近强轮廓支持的短弱链可以被接受。

最初较宽松的规则在固定噪声试验中会接回更多噪点，因此没有作为默认交付。默认三强种子的规则更保守，代价是很小的真实点状特征、没有强种子支持的长弱轮廓仍可能丢失。不要将 E2 称为完整 Canny 或全图滞后追踪。

普通高低阈值连接的定义可参考 [scikit-image 的滞后阈值说明](https://scikit-image.org/docs/stable/api/skimage.filters.html#skimage.filters.apply_hysteresis_threshold)。本实现额外加入方向和种子数条件，且只在有限窗口追踪，与该全图定义有明确区别。

## 参数与回退

- 顶层 `E2_LINK_ENABLE=1`：默认 E2L；设 0 得到 E2N，需重新编译。
- 顶层 `E2_MIN_SEEDS=3`：默认强支持数。设为 2 更宽松，容易同时接回噪声，本轮不作为默认固件。
- `E1_NMS_ENABLE=1`、`E1_NMS_STRICT_TIES=0` 保持不变；关闭 NMS 时新增连接也旁路，仍可走原 Sobel。
- 核心 `COMPARE_PAIR_EDGE=1`：M3 二值预览按列对取 OR；设 0 恢复原 E1 偶数列取样。仅用于编译配置，原按键不被占用。
- `img_edge_link` 模块还保留 `BRIDGE_ENABLE`，模块仿真覆盖桥开、关两种情况。

原阈值范围 4～128、步进 1 及长按逻辑不变，只把板级上电默认值改为 50。M6 的 R/G/B/P 调节、冻结/解冻、诊断和模式入口保持；色彩仍为 PH2 BGGR、十六进制增益 R240/G180/B240。相机初始化与曝光、DDR、MIPI、HDMI、PLL、复位及 SDC 不改。

## 行缓存、延迟与显示模式

新 5×5 描述符窗口采用四行 RAM，行帧边界只使用有效邻域，不清空或读取未初始化 RAM 来生成边缘。RGB、幅值、显示配置、阈值判定及 DE/HS/VS 按同一像素令牌延迟。

为控制 RAM，占用期间只缓存 RGB；原灰度可由同一 RGB 经过完全相同的 `img_rgb2gray` 公式重算，再整体补一拍。仿真核对其灰度、彩色和 M5 值与冻结 E1 一致，不重新调整色彩或改变 Sobel 的输入。

两版核心延迟统一为 `5*HTOTAL+60`。1080p、HTOTAL=2200、148.5 MHz 时为 11060 周期，相比 E1 增加 4433 周期，约 **29.85 微秒**。仍是一时钟一像素，不增加整帧缓存或反压。这是处理核的固定额外延迟，不代表实测相机到屏幕总延迟，也不改变相机本身 30 fps 的配置。

- **M2**：所选二值结果，用于主要 A/B 判断。
- **M3**：同一上一源行的彩色原图/边缘图；两边仍展示完整视场。左图颜色与取样不变，右图避免奇数列细线被缩略丢失。
- **M4**：相同中心像素上叠加边缘，检查定位和重影。
- **M5**：保留原始完整幅值的灰度映射，不换成 NMS 或连接后的幅值。
- M0/M1/M6、参数条、诊断与冻结功能保留。

## 已完成的验证和实际边界

完整数值、时序和修改清单见 `reports/V10_E2_VALIDATION.md`。测试包括：冻结 C2/E1 核心逐像素回退对照、M0/M1/M5 和同步一致性、M3 奇数列细线/奇偶宽度/原取样回退、阈值与模式切换、边界及连续帧、局部图独立参考，以及 13 张固定输入的 39 个实际 RTL 输出。

固定图覆盖棋盘、杯纹、文字、PCB、公开人像、三帧合成运动、已知短弱带及四档固定随机噪声。除公开人像外，均明确标为合成输入；实拍图来自 [公开测试人像来源](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut)，不进行识别。没有人工标注真值，不报告真实场景 Precision/Recall/F1；白点、孤立点和连通分量只作描述性计数。

只有已知平坦背景 ROI 的噪点计数、已知弱带的局部覆盖率有合成真值，不能推广为实拍准确率。对比图中杯纹和低对比 PCB 仍有缺口，较强噪声仍有残留；桥可能在局部多保留一个有梯度支持的像素，不能承诺每处恰好单像素宽或所有轮廓连续。

## 实板测试顺序

1. 固定照明、物体、机位、距离、预处理；先用 E2N，再用 E2L，均保持 T=50。确认普通页标识、PH2 和增益不变。主比较用 M2，避免缩略显示影响判断。
2. 对纸杯花纹、印刷文字、PCB 细线路、人脸五官、棋盘格分别看：有用弱线是否补回，平坦背景是否少点，斜线/圆弧/角点是否断开，是否错接邻近真实轮廓。保留同一位置照片作对照。
3. 用 M3 检查两侧对应与奇数列细线，用 M4 检查红线贴合位置；M0/M1/M5 应保持原有内容。若新增连接损失细小真实特征，记录具体位置后回到 E2N，不用单纯增加白线数作为判据。
4. 在两版上都检查 T=40/50/60 的效果，并覆盖上下限、反复切模式、冻结/恢复、运动、至少 30 分钟连续运行。T=40/60 是实板待测项，不是本轮已完成的固定图数据。
5. 记录 CAM/DDR/SCREEN、U/D/R/L/O、黑屏/无信号及是否新增拖影。编译时序通过不能替代真实 HDMI、DDR 和长期运行确认。

## 离线复现

工程入口为 `ti60f225_oob.xml`。用当前 Efinity 执行 compile（map/interface/pnr/pgm）；连接关的独立缓存由 `scripts/prepare_e2_nms_build.py` 准备，包内不包含临时构建缓存。

- `scripts/check_e2_scope.py`：在当前工作区检查稳定版本未改、改动范围和约束。独立解压时可使用 `--standalone` 检查包内冻结基准。
- `scripts/check_project.py`、`scripts/test_project_structure.py`：工程结构与公开 IP 端口检查。
- `scripts/run_tests.py`：完整回归，需 Icarus，或有许可的 ModelSim/Questa。
- `scripts/verify_e2.py`：局部窗口/连接的独立模型与 RTL 对照。
- `scripts/verify_e2_images.py`：实际 RTL 三路固定图对照，需 NumPy/Pillow。
- `scripts/finalize_e2.py`、`scripts/package_e2.py`：核查两次真实编译、验证和 SHA256 后收集、打包；拒绝覆盖已有交付包。

本机工具位于 `D:\FPGA`，Icarus 位于工作区 `tools/iverilog/bin`，Pillow 位于 `tools/python_libs`。测试输入已随包保存，不需要重新下载图片。
