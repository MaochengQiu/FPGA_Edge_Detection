# 扩展路径

本版已完成 Canny 升级之前的主干和几个增强项。没有把空模块称为已经完成的算法。

## Canny

已有 Gaussian 前处理、完整有符号梯度、十一位幅值、通用位宽窗口和方向量化 helper。下一步可依次加入：

1. 梯度幅值与方向打包，通过同一邻域窗口，使 NMS 中心方向与中心幅值对应。
2. NMS 明确方向编码、平局抑制规则和边界；数据宽度与流水时序必须重算并同步调整原图对齐。
3. 双阈值寄存器原子提交，验证 `low <= high`，输出背景/弱/强分类。
4. 局部连接只能标注为近似版本。严格 hysteresis 应做连通域或边缘跟踪算法设计和独立验证，不能用固定几次扫描宣称任意图像都正确。

新增算法无需改变采集或 HDMI PHY，但必须更新 `img_pipeline` 的延迟和边界半径。可从目前的 `Gx/Gy` 和幅值接口分支，不要从八位显示幅值反推梯度。

## 帧差、历史比较与回放

三缓冲目前只保护一个显示帧和一个最新完整帧，没有任意历史保留。需要扩展帧描述符、缓冲所有权和额外 DDR 访问仲裁；显示读取优先保障，算法访问应通过 FIFO/握手调度。

RAW8 摄像头帧、RGB 图、梯度幅值、分类图必须有各自的格式和地址区间，不能直接复用相同 byte stride。新写者和读者应根据真实存储位宽计算带宽与容量。

## 控制与状态

`img_control` 已有同域 host 写接口，可挂 UART/APB 适配器。串口协议与 RISC-V 总线尚未实现，不能把 host 端口视为现成串口功能。多位跨域参数及计数应使用握手快照。

## 行级低延迟

集成版仍经 DDR，是先验证功能和稳定显示的路径。要达到摄像头到显示的行级延迟，需要另建无整帧缓存的时序匹配路线，核对相机 raster、显示 raster、跨域 FIFO 波动和长期帧率关系。单加一个 `source_mux` 不足以完成这项工作。
