## 本次目标与赛题对应

依据上传的《易灵思.pdf》赛题四第12–16页，继续使用现有摄像头 → DDR → HDMI 和 FPGA Sobel 流水线。此次不改固定硬件参数或接口；只让五官、杯子花纹等低对比度边缘更容易出现，并让左、右真正表示**同一画面的处理前 / 处理后**。

## 新分屏的数据映射

令输出宽度为 `W`（开发板固定为1920），`H = ceil(W/2)`，输出坐标为 `(x,y)`。源处理后的灰度/Sobel 与源原始RGB在 `img_pipeline` 中已完成时序对齐。新合成器中：

- `x < H`：左侧显示 `RGB(2x,y-1)`；
- `x >= H`：右侧显示 `Edge(2(x-H),y-1)`；
- `y=0`：显示黑色，避免使用复位后未经初始化的 RAM；
- 右边白色代表 Sobel 幅值大于或等于当前阈值；黑色代表不满足阈值。

这在 1920×1080 HDMI 上呈现两幅 `960×1080` 的完整水平方向视野，每幅画面会在水平方向被压缩2倍；这不是保持原长宽比的缩放。该实现**只消耗约48,000bit 额外的行缓存**（两个 `960×25bit`），无需修改DDR寻址、视频接口频率或生成第二个完整帧。为消除压缩，可短按KEY3选择显示模式0（全屏原图）、2（全屏边缘）或4（全屏红色边缘叠加）。若未来需要两幅无变形、等比例缩小的图像，需增加帧级缩放/缓存和独立读时序，不属于本次保留接口的低风险改动。

## 调试建议

1. 解压后使用 Efinity 打开根目录 `ti60f225_oob.xml`，重新运行 Design Check、Synthesis、Place & Route、Timing Analysis 和 bitstream。不要直接复用旧 bitstream。
2. 上板后等待 DDR 稳定，默认出现**左彩色、右黑白边缘**。把带细纹的杯子与人脸置于镜头中，左右应出现相同的整体形状，右侧不应只看到输入画面的右半部分。
3. 右侧仍只有明显外轮廓：按 KEY2 降低阈值（64 → 56 → 48 → 40）；细边过密或噪声太多：按 KEY1 增大阈值（64 → 72 → 80）。阈值在下一帧生效。
4. 如果存在散点噪声，长按 KEY3 切换为中值滤波；若中值损失细小花纹，再长按进入 Gaussian 或旁路模式。短按 KEY3 切换显示模式，可切到模式5查看梯度强度图。
5. 核实 VGA/HDMI 时序、DDR 读写、摄像头帧率与原工程一致；留意本次双行 RAM 的 BRAM 资源用量和时序裕量。对阴暗环境的低对比度细节，优先提高照明/相机曝光，而不是无限降低阈值。
