# V11-G1 单目标几何识别实验

工程D:/FPGAdemo/V11_G1/ti60f225_oob，由v11-gray-baseline独立复制。当前固件programming/ti60f225_oob_V11_G1.bit，屏幕标识EGR。原基准源码与bit保持。默认M3/T50/PRE2；短按模式键到M7查看彩色视频上的CIRCLE/SQUARE/RECT/NONE，普通页长按切PRE。M0～M6保持，M3左灰度右边缘、M4红边、M5幅值和M6诊断不改。

## 使用与限制

本阶段按用户限定，在干净背景的中央ROI检测一个完整大目标。1080p ROI为x480..1439、y270..809；不画蓝色ROI框，需把目标完整放在此区域内并留至少8像素边距。目标外框宽高建议均大于64像素，四边较完整；正方形和矩形应近水平/垂直。圆形可改变位置和尺寸；仅显示一个目标。背景大量干扰、轮廓不明确或不完整时应看到NONE。若边缘图本身有明显断线，先看M2和PRE/T，不把图像中看得见的物体当成其二值轮廓一定可用。

圆形用绿色中心十字和CIRCLE，正方形/矩形用绿色框与SQUARE/RECT。NONE只有灰色文字，没有识别框。检测坐标是块级量化，边界误差最多约8像素；中心取量化框中点。结果来自上一完成的输出视频帧，有一帧结果滞后，移动中框会暂时位于前一帧的位置；没有实现运动补偿或跟踪。不是任意旋转、多目标、全局CCL或Hough。

## 数据与时序

识别使用img_pipeline中final_edge（正是debug_edge的驱动值）及同一final_token[43:40]控制位，在进入img_composer前分支。没有把debug_edge直接与composer后的DE拼接。识别坐标和M7绘图坐标都从该令牌的DE/VS生成；绘图与原图一起经composer的一拍寄存器。后面的Gamma/HUD/编码路径未改。M0～M6和全管线原延迟仍为13261拍。

中央ROI采用8×8块内OR：每个输入边缘都进入汇聚，不是隔点采样。行内累积、跨8行OR后写入120×68二值小缓存（含末行不完整块）；每帧所有缓存单元均被覆盖，无须整帧清零。OR能保留单像素边，但也会合并相距很近的细节，不能称为无损轮廓。

ROI结束后串行FSM读取小缓存，计算候选包围盒、中心、宽高及半径平方。单目标假设下ROI内边缘整体作为候选；杂边会扩大候选，因此本版主动拒绝不满足几何约束的输入，不声称复杂背景分割能力。

矩形必须覆盖左右边每个行块和上下边每个列块、四角都有支持，且至少7/8边缘点落在边带；再以长宽差不超过较大尺寸1/8区分SQUARE/RECT。圆形需要近方形边界框（长宽比不超过1.2）、至少90%边缘点满足半径平方容差、8个方向扇区均覆盖，以及除端部外每行左右/每列上下均有径向有效边缘。半径容差含格点量化项，属于有限分辨率的几何判据，不是任意噪声条件下的数学证明。

完整性只能在汇聚分辨率和容差内判断：小于一个块的缺口可能被OR掩盖。测试拒绝的是可分辨的缺边、缺口弧、三角形和密集干扰，不能夸大为对所有残缺或所有非规则形状绝不误检。

FSM在ROI以下的空闲行完成，约4×8160+边界扫描拍，小于1080p配置的剩余270行窗口。pending结果只在VS发布；未就绪时输出NONE，识别没有对视频施加反压。失效时M7背景仍为彩色。G1_ENABLE=0可编译回退到旧M7，旧实现另存reference/M7_baseline_img_composer.sv。

## 验证与复现

scripts/build_g1.ps1执行Efinity实际编译。Icarus沿用scripts/icarus_direct.py，环境RTL_SIM=icarus_direct及现有VVP路径。定向命令scripts/run_tests.py tb_g1_shapes、tb_g1_rgb、tb_g1_overlay；scripts/verify_g1_core.py做双核心回归，scripts/verify_g1_disabled.py测试关闭支路。软件环形历史数组只是测试计分板，不是RTL识别。

形状测试包含不同尺寸圆、方框、长方框、三角形、空白、缺边、缺口圆弧、密集干扰和逐帧移动；检查分类、上一帧坐标和帧内不变。RGB集成使用实际PRE2→Sobel→NMS→连接，检查实心形状及移动卡。全核心包含1920列真实行周期，核对全部同步/幅值/边缘、M0～M6像素及M7背景/覆盖时序；另检验关闭支路旧M7、绿色标记、NONE不画框和HUD标签。

这些仍是离线测试，特别是识别集成测试没有替代真实相机、光照和纸张测试。实际资源/时序、修改清单、固件校验见reports/V11_G1_VALIDATION.md和g1_release_manifest.json。没有实板验收结论。工程继承的旧报告和README入口均为历史，以本说明和G1前缀结果为准。
