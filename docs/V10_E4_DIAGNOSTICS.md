# E4：黑屏/无信号诊断固件

这次不继续调画质。用户实板反馈 E3B/E3W 肉眼差异小，PRE3 噪点最多、PRE1/2 略少；M2 有黑屏/闪烁，异常后 T/PRE 保持，黑屏时提示文字也消失或显示器提示无信号。HDMI 线和摄像头排线已更换，移动开发板似乎影响现象，但尚未确认因果。

当前尚未定位实板故障根因，没有宣称已经修复。E3 发布目录与固件保留。E4 使用 E3B/E2L 算法，关闭 E3 弱轮廓补充路径；普通摄像头分支的算法、颜色、复位与视频链路保持。

## 先用 E4T 分离输出链路

烧录 `programming/ti60f225_oob_V10_E4_HDMI_Test.bit`，确认标识 E4T。固定测试图为左侧白线网格、右上彩条、右下黑白块，右下角有变化块，V 数字持续变化。它不是摄像头图像，不响应切页成为其他画面，也不需要调阈值。

测试图源与 1920×1080、2200×1125 总时序在 148.5 MHz 像素域内独立生成。它不依赖摄像头是否出帧、DDR 是否完成校准或边缘算法是否工作。测试分支只使用外部复位及 USER_PLL 锁定状态释放其自己的诊断复位；最终 DVI 编码器、LVDS 串化配置、引脚、输出使能和 SDC 没有换成另一套。HUD 的 C/B/S 等仍可反映后台采集状态，在 T 版中不用于判断固定图是否正常。

保持现有线材，先固定开发板观察；不用再反复换线、降阈值或调颜色。若固定图也闪烁/无信号，优先排查共同的最终输出链路、显示器输入、接头/焊接、相关时钟或供电。LED2～7 为历史锁存位，亮着不等于当前帧流或 HDMI 正常；LED0/1 才分别为核心与摄像头像素时钟心跳。

若 E4T 稳定而 E4D 不稳，重点回到正常视频输入/处理/复位和负载相关问题；这不是完全排除信号完整性或负载相关压降的证明。两版的逻辑负载不同，不能把“固定图通过”称为完整硬件签核。

摄像头排线重插前断电。现阶段不必故意反复晃动板子；如自然触碰某个接头就伴随故障，请记录具体接头与动作，单凭“移动整板”还无法定位。

## E4D 正常图像诊断

烧录 `programming/ti60f225_oob_V10_E4_Diagnostic.bit`，确认 E4D。先设 T=68、PRE=1，作为明确区别于上电 T=50/PRE=0 的标记；在 M2 观察。该设置用于辨认复位与保留状态，不是宣布最佳画质参数。

普通页多出一行诊断文字：

| 字段 | 含义 |
|---|---|
| C | 摄像头帧事件数，每 60 个输出 VS 周期更新 |
| B | 完成 DDR 写帧事件数，同一窗口更新 |
| S | 新显示帧被选用的事件数；不是独立测得的 HDMI 刷新率 |
| U | 显示输入欠载粘滞标记 |
| D | AXI 读帧错误粘滞标记 |
| R / L / O | 丢弃帧、迟到请求、采集溢出标记 |
| F | 冻结状态 |
| K / LAST | 消抖后的按键累计次数（十六进制）与最后按键 1/2/3 |
| V | 到达最终 HUD 的 VS 计数，十六进制循环；变化说明该帧时序仍在前进 |

K 增加且 LAST=3 后，M2→M3 是模式键短按的正常行为，不表示重新初始化。若无人操作时 K 增加，才有证据进一步检查按键接触、干扰或识别。若 T/PRE 同时回到 50/0，再考虑控制器复位；保持默认值不变本身不能用来排除复位。

若画面黑但这行文字与 V 仍在更新，说明最终像素输出至少仍能显示状态，应记录 U/D/R/L/O。若连文字一起消失并且显示器报无信号，先记录显示器提示和恢复后这些标记，不要用阈值调节掩盖现象。标记可能随视频复位被清空，0 不能证明此前从未发生过错误。

## 离线证据及其边界

`tb_m2_starvation` 在真实 img_video_out、img_control、E2L 核心的输入接缝注入一次丢帧：M2 黑一帧，T68/PRE1 保持，DE/HS/VS 连续，下一帧恢复。它证明“欠载可以使内容变黑”，没有复现实板的电气掉链或证明欠载是本次故障原因。

`tb_hdmi_test_pattern` 检查独立图源的小尺寸 20 帧，以及实际 1920×1080、2200×1125 两帧的逐时钟光栅与像素计数。两版 HUD 检查 PRE、错误标记、按键信息、V 计数和同步延迟。加上原按键/冻结及 video_out 故障恢复，共 8 组定向验证。因为没有修改边缘核心，不将 E3 的 52 图结果冒充 E4 新跑结果，也不重复跑图像质量实验来证明 HDMI 故障已解决。

真实 Efinity 编译、时序、CDC、固件 SHA256 由 `reports/e4_release_manifest.json` 和 `V10_E4_VALIDATION.md` 汇总。没有实板测试结果时，状态只会是诊断用候选。

## 复现入口

同 E3 的 Icarus direct 环境运行 `scripts/verify_e4.py`；结构检查为 `check_project.py`（78 源、29 自定义模块）及 `test_project_structure.py`。`check_e4_scope.py` 检查 E3 冻结和本轮改动范围。

`prepare_e4_test.py` 建立 T 的独立缓存，只切换顶层 E4_HDMI_TEST。`build_e4.ps1 -Variant D/T` 执行真实 compile。D 分支保持原 edge_pixel_rst_n；T 的测试复位是独立诊断分支，不作为正常系统复位修复。
