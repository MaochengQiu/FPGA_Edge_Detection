# 架构与数据契约

C1色彩增量：现有Debayer只修正一处R/B插值邻域；RAW前级精确1倍，后级RGB一次校色、四舍五入饱和；仍为一拍RGB/DE/HS/VS共同延迟。M6增益步进1/32及256样本裁剪计数。其余本文架构与算法保持V10，详见 `V10_C1_COLOR.md`。

## 数据路径

采集 → CSI RX → RAW10 取高八位 → RAW8 打包 → 捕获异步 FIFO → AXI writer → DDR → AXI reader → 显示异步 FIFO → 连续 raster（img_video_out）→ Debayer → RGB 双像素转单像素 → 新增视频处理 → 等延迟 Gamma/旁路 → 最终 HUD → HDMI。

新增视频处理：RGB2Gray → 前处理窗口 → 旁路/Median/Gaussian/Unsharp → Sobel 窗口 → 梯度 → 阈值 → 显示合成。RGB 与原始灰度分支延迟至阈值输出位置。

## 模块与时钟

| 子系统 | 时钟 | 数据格式/速率 |
|---|---|---|
| 摄像头流 | `i_mipi_rx_pclk` | 沿用 v7 的四像素 RAW 打包 |
| DDR DMA、帧管理 | `core_clk` | AXI128，读一项 burst；写最多4项响应在途 |
| 连续 raster、Debayer | `vid_clk_dvi2` | 两 RAW/RGB 像素每拍 |
| 算法、按键、合成 | `hdmi_tx_slow_clk` | RGB888，一个活动像素每拍 |
| PHY、HDMI 串行输出 | 原 v7 的相关 PLL 输出 | 维持原平台配置 |

每个新增时钟域使用 `img_reset_sync` 异步置位复位、同步释放。两个跨域 FIFO 两端必须同时进入复位，不能单独清一端指针。

## 视频契约

- 编译时固定 `WIDTH`、`HEIGHT`、`HTOTAL`；一行两个活动区开始之间必须恰好是 `HTOTAL` 个时钟。
- `de` 表示完整显示活动区，不因为窗口缺失而缩短。
- HS/VS 为正极性。每帧先出现 VS，再出现活动像素；活动区每行连续，行间必须有消隐。
- `ctl={sof,vs,hs,de}`。SOF 与首个活动像素同行，数据和控制走等长路径。
- 算法主干无反压，活动像素每拍一个；DDR 和 AXI Stream 保留握手。
- 前处理窗口不足时，中值/高斯/锐化输出边界零；旁路保留原始灰度。
- 最终边缘图：旁路前处理屏蔽一圈边界，中值/高斯/锐化屏蔽两圈；原图/原始灰度完整显示。
- 显示模式3：**左 RGB、右二值边缘**，分别显示来自同一输入画面完整宽度的 2:1 水平抽样样本；需要在合成器中使用两个 25bit×ceil(WIDTH/2) 行缓冲。源行 y-1 在显示行 y 上呈现，首行填黑，因而无法保持原视频的横纵比例。此模式与输出其他模式同样只增加一级寄存器延时，不改变流 DE/HS/VS。
- `window_valid` 表示窗口完整，不能替代 `de`。
- 外部配置必须是整帧快照，保持至下一输入 SOF。流水总延迟必须小于输入帧周期，以便下游收到 SOF 前全局快照不会再次被下一帧覆盖。平台默认时序满足此条件。

## 延迟与对齐

`img_delay.CYCLES=1` 表示一个采样寄存器。若输入记录索引为 n，那么一段 N 级路径在输出记录索引 n+N−1 对应它；测试脚本使用这个约定。

窗口当前到达点是右下角，计算中心是 `(x-1,y-1)`。行缓存容量和中心对齐距离不同。

| 段 | 采样级数 |
|---|---:|
| 灰度化 | 1 |
| 单个窗口到中心时序 | `HTOTAL+3` |
| 前处理运算及等长旁路 | 9 |
| Sobel 运算 | 4 |
| 阈值 | 1 |
| 显示合成 | 1 |
| 整个 `img_pipeline` | `2*HTOTAL+22` |

窗口的两级来自同步 RAM 读取和横向窗口寄存器。旁路、中值、高斯、细节增强均经同样的中心及运算延迟。默认 HTOTAL 下总计 4422 级；平台 Gamma/旁路另外增加一级。

长延迟用循环 RAM，启动填充期间输出零，RAM 内容不复位。RGB 对齐和控制对齐包含消隐时钟。

## 运算格式

- RGB 端口：`rgb[23:16]=R`，`[15:8]=G`，`[7:0]=B`。
- 灰度：`(77R+150G+29B+128)>>8`。
- 窗口：`window[7:0]=p00`，逐行向右排列，到 `window[71:64]=p22`。
- Median：九级 odd-even transposition 网络，最终取第五小值；每级并行比较。
- Gaussian：3×3 二项核，权重 `1 2 1; 2 4 2; 1 2 1`，总权重 16，舍入移位。
- 细节增强（前处理模式3）：`Gaussian=clip(round((1 2 1;2 4 2;1 2 1)卷积/16))`，`Unsharp=clip(3×center−2×Gaussian,0,255)`，在同一9级时延内完成，无额外行缓存；它会提升微弱细节，也可能放大传感器噪点。
- Sobel：四级流水，`Gx/Gy` 十一位有符号，L1 幅值十一位无符号；阈值比较使用 `>=`。
- Threshold=0 会把可信内区的零梯度也判为边缘，这是选择 `>=` 的明确结果。
- 方向辅助：四个梯度方向，交叉乘法近似 22.5°/67.5°分界，未集成 NMS。

## 参数接口

`img_control` 的 host 写接口和按键处于同一像素时钟域。若以后从 UART/APB 或 RISC-V 写入，应在外围使用跨域握手，不要逐位同步多位参数。

| `cfg_addr` | `cfg_data` |
|---|---|
| 0 | 十一位阈值 |
| 1 | 前处理模式：0旁路、1中值、2高斯、3细节增强 |
| 2 | 显示模式：0原图、1灰度、2边缘、3分屏、4叠加、5幅值、6白平衡诊断；其他值忽略 |
| 3 | bit0：冻结请求 |

板级 host 写入绑零，实际交互使用按键。V10 默认阈值24、范围4～128、前处理0（旁路）、显示3（完整场景左右复制），阈值步进1。host/按键均钳位；长按阈值键支持延时连调。模式6的 KEY1/2 调白平衡增益。普通页参数条和模式6的T使用十进制显示。

## DDR 帧存储

- 当前像素存储格式限定 RAW8，一个真实像素一个字节。`WIDTH` 是像素数，不是输入 word 数。
- 相机 VS 下降沿重置打包计数并准备采集随后的活动帧；首个 DE 数据产生 SOF。既测试了帧前短脉冲 VS，也测试了 CSI generic 的电平式 VS，后者上电可能跳过第一帧，等待首次下降沿后开始采集。
- `FRAME_BYTES=WIDTH*HEIGHT`，必须能被 AXI 字宽整除；输入/输出字宽还必须整除 AXI 字宽。平台固定输入32、输出16、AXI128。
- 帧地址按 4KiB 对齐，三帧使用固定跨度。帧地址从零开始；以后增加其他存储区需一起修改地址规划。
- `MAX_BURST` 单位为 beat 数，与 AXI `AxLEN=beat数−1` 区分；DMA 自动拆分 4KiB 边界和尾部短 burst。
- 写者只有等全部 W 握手及 B 响应成功后才发布帧。地址选择切换后留一拍再开始下一帧。
- 读者在请求处选帧；旧 DMA 必须已完成，旧像素可在 FIFO 中继续消费。忙时请求记入 `late_requests` 并保留一项 pending，旧 DMA 完成后处理。
- 捕获/显示 FIFO 默认各2048项，AXI128。连续 raster 缺数据时填黑并丢弃帧尾，保留下一个 SOF 到下次有效帧起点；HS/VS/DE 不受影响。
- 没有完整帧时输出黑帧；冻结读 bank，摄像头继续在其他 bank 更新最新完整帧。
- 这是“最新完整帧”策略：不能保证不同采集/显示帧率下每帧都显示，已完成但未显示的旧帧可能被替换。
- 三缓冲不等于历史回放，也不提供被保护的任意多帧历史。
- FIFO 溢出时丢弃该采集帧剩余数据；下一 SOF 触发 writer 填完旧事务并拒绝发布旧帧。若摄像头彻底停止且没有下一 SOF，未完成 writer 会等待，不会发布破损画面。
- 读响应错误计数并将该 beat 显示为零；异常 RLAST 仅计数，严重协议违例可能需要复位恢复。

状态：`completed_frames`、`rejected_frames`、`late_requests`、`read_errors` 在 AXI 域；`capture_overflows` 在相机域。以后读取这些多位计数应使用快照握手。
