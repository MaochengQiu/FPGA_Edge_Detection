# V10-C2.1：保存实板确认的色彩预设

本轮仍在原 V10 工程中修改，入口为 `ti60f225_oob.xml`。相对 C2，仅修改控制器的四个复位常量及 HUD 版本标识；Debayer 算术、RGB 舍入/饱和、行缓存、灰度/Sobel、预处理、DDR、MIPI、HDMI、PLL、复位连接和摄像头曝光均不改动。

## 实板确认及默认值

2026-10-31 用户确认正确排列为 **PH:2 BGGR**，并提供增益 `R240 G180 B240`。照片中的字段为 `GAIN`，采用十六进制 UQ2.8 格式，不是 RGB 像素亮度。

| 设置 | 上电默认值 | 实际含义 |
|---|---|---|
| PH | 2，BGGR | 第一行 B G，第二行 G R |
| R 增益 | 0x240 | 576/256 = 2.25 倍 |
| G 增益 | 0x180 | 384/256 = 1.5 倍 |
| B 增益 | 0x240 | 576/256 = 2.25 倍 |

C2.1 上电或按 KEY0 复位后自动恢复以上预设，无需再次手动切相位和调增益。这是编译进固件的默认值，没有新增 Flash 写入或相机寄存器操作。运行中仍可手动调整；其他排列继续作为调试入口保留。用户确认只针对当前模组、裁剪/镜像配置和测试条件，不能推广为所有 SC431HAI 模组的通用配置。

烧录 `programming/ti60f225_oob_V10_C2_1.bit`。M6 第一行显示 **C2.1**，第四行显示 **C2.1 RAW1X CLIP**，默认 `PH:2 BGGR`，GAIN 为 `240 / 180 / 240`。普通模式参数条也显示 C2.1。

## 照片中的裁剪与白平衡

附图中 RAW 均值为 `32 / 3F / 2D`，OUT 均值为 `5E / 57 / 54`，三通道 CLIP 分别为 `00F / 00F / 00F`，样本数为 `100`（十六进制 256）。即每个通道有 15/256，约 **5.9%** 的抽样点在后级增益处理时裁剪到 255。

画面正对明亮灯具，既不是均匀白/灰卡，也不能用来完成白平衡标定。因而本版按用户提供值保存为实测起点，不声称该增益对所有场景都最佳。逐像素先乘增益、舍入/饱和，再对结果取均值；存在裁剪时，OUT 均值无需等于 RAW 均值直接乘增益。

复核时将白/灰卡放在普通场景照明下并覆盖中央采样区域，避开灯具、背光和镜面反射。先保持 PH2，再检查 OUT 三通道是否接近及 CLIP 是否合理，同时观察肤色、真实红绿蓝物体和纸杯图案。不要为消除灯具高亮而改变 Bayer 排列，也不要把彩色物体的通道均值强行调成相等。

若普通白/灰卡仍大量裁剪，可手动按相同比例降低三通道增益；例如 `180/100/180` 与本版 `240/180/240` 的比例相同、整体亮度较低。此例没有自动写入默认值，避免擅自改变用户确认的画面亮度。摄像头曝光配置本轮保持不变。

照片中的 CAM/DDR/SCREEN 均为 30，R/L/O/U/D 状态均为 0。这记录了该次拍照时刻的状态，不能替代 C2.1 的长时实板稳定性测试。反馈照片与数字记录保存在 `reference/c21_board_feedback`。

## 按键与模式

- 上电仍为 M3，短按 KEY3 三次到 M6；模式编号和顺序不变。
- M6 长按 KEY3 每次约一秒并释放，选择 `R → G → B → P → R`；KEY1 增、KEY2 减。R/G/B 步进 `008`（1/32），范围仍是 `080～240`。R/B 上电已在最大值，继续加应保持 `240`；减一次应到 `238`，不能变黑或回绕。
- `SEL:P` 时 KEY1/2 调排列；切换仍在下一帧消隐期生效。复位恢复 PH2。
- 其他页面 KEY1/2 仍调阈值，4～128、默认 24、步进 1；长按 KEY3 仍切预处理。KEY1+KEY2 仍冻结/解冻；KEY0 仍复位。
- M0 彩色、M1 灰度、M2 二值边缘、M3 原图/边缘对比、M4 红轮廓叠加、M5 梯度灰度、M6 调试均保留。本轮没有增加 NMS、双阈值、弱边缘连接或 Canny。
- M6 下方固定色块依次为红、绿、蓝、白、黑，仍绕过相机和增益，用于显示通道核查。

## 上板复核与回退

1. 确认固件标记 C2.1、PH2 和默认增益；断电上电及 KEY0 复位后不需重调。
2. R/B 增益到顶反复按加键，再按减键，确认值饱和保持、画面和 HDMI 连续。
3. 用白/灰卡复核增益；用肤色、红绿蓝物体、彩色纹理确认颜色和细节。切换 M3/M4/M5/M6、运动和冻结/解冻，观察 U/D/R/L/O。
4. 若需回退，烧录原 `programming/ti60f225_oob_V10_C2.bit`。C2 完整包仍在 `version/packages/ti60f225_oob_V10_C2_color.zip`，修改前的控制器和 HUD 在 `reference/c21_baseline/rtl`。

新包为 `version/packages/ti60f225_oob_V10_C2_1_preset.zip`，验证结果见 `reports/V10_C21_VALIDATION.md`。完整编译沿用 `efx_run ti60f225_oob.xml --flow compile`；发布使用 `scripts/finalize_c21.py` 和 `scripts/package_c21.py`，不使用旧 C2 发布脚本覆盖原产物。色彩实板复核后再继续边缘质量优化。
